📊 Mesclar Planilhas

Faça upload de múltiplas planilhas e mescle-as inteligentemente

Como funciona:

  • Selecione ou arraste múltiplos arquivos Excel (.xlsx, .xls) ou CSV
  • O sistema lê todas as abas de cada arquivo (suporta até 100 arquivos com até 100 abas cada)
  • Colunas com o mesmo nome são mescladas automaticamente
  • Nenhum dado é perdido - todas as colunas são preservadas
  • Visualize o resultado e baixe a planilha mesclada

💡 Processamento Otimizado para Memória:

  • Modo Streaming: Os arquivos são processados um por vez com pausas frequentes
  • Navegadores recomendados: Chrome, Edge ou Firefox (mínimo 4GB de RAM)
  • Importante: Não feche a aba durante o processamento - acompanhe a barra de progresso
  • Dica: Feche outras abas/programas do navegador para liberar memória
  • Sistema otimizado para processar até 100 arquivos com 100 abas cada
  • Processamento em lotes de 100 linhas com pausas para evitar travamento
  • Após o download, clique em "Limpar Tudo" para liberar toda memória utilizada

⚖️ Detecção Automática de Números Processuais CNJ:

  • Identificação automática: O sistema detecta números processuais de 20 dígitos
  • Normalização: Formata automaticamente para NNNNNNNN-DD.AAAA.J.TR.OOOO
  • Priorização: Números processuais sempre aparecem na Coluna A (primeira coluna)
  • Validação: Verifica dígitos verificadores para garantir integridade
  • Aceita números com ou sem formatação (só dígitos ou com pontos e hífens)
