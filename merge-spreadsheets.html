📊 Mesclar Planilhas

Faça upload de múltiplas planilhas e mescle-as inteligentemente

Como funciona:

  • Selecione ou arraste múltiplos arquivos Excel (.xlsx, .xls) ou CSV
  • O sistema lê todas as abas de cada arquivo (suporta até 100 arquivos com até 100 abas cada)
  • Colunas com o mesmo nome são mescladas automaticamente
  • Nenhum dado é perdido - todas as colunas são preservadas
  • Visualize o resultado e baixe a planilha mesclada

💡 Processamento Otimizado para Memória:

  • Modo Streaming: Os arquivos são processados um por um, economizando memória
  • Navegadores recomendados: Chrome, Edge ou Firefox (mais de 4GB de RAM)
  • Dica: Feche outras abas do navegador antes de processar volumes grandes
  • Sistema otimizado para processar até 100 arquivos com 100 abas cada
  • Após o download, clique em "Limpar Tudo" para liberar memória
